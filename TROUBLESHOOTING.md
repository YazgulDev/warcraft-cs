# Решение проблем

| Симптом | Проверка |
|---|---|
| F6 ничего не меняет | Одиночная игра, свой живой юнит, Game.dll строго 1.26.0.6401. Прочитайте `WarcraftCS/WarcraftCS.log` в приватной копии. |
| Unsupported Game.dll | Нужна установленная 1.26a x86; другие патчи/версии не поддерживаются. |
| Не найден compiler | Установите workload C++ и x86 MSVC через Visual Studio Installer. |
| Не найден Python/NumPy | Python 3.10+, повторите setup; при необходимости `-PythonExecutable`. |
| Не найден v_*.mdl или звук | Укажите настоящую папку cstrike с локальными файлами своих моделей/звуков. |
| Чёрное окно/проблемы драйвера | Запуск использует OpenGL. Попробуйте `play.cmd -Windowed`, обновите драйвер GPU. |
| Нет прежних сохранений | Это отдельная приватная копия; переносите нужные save вручную с резервной копией. |
| E не подбирает | Нужен свободный настоящий инвентарь; стан/скрытие/транспорт запрещают подбор. Backpack крипов не активирует руны/тома. |
| Оружие не действует | Проверьте здоровье, stun/disarm, наличие патронов и режим урона; у безоружного существа Mode=hero даёт 0. |
| Странная кастомка | Вернитесь по F6 в RTS. Скрипты камеры/юнита могут конфликтовать; приложите название/версию карты и обезличенный лог. |
| H/O изменяют приказы рабочих | Набираются свои подвижные юниты рядом, включая рабочих. J освобождает отряд; уменьшите RecruitRadius. |
| Не устанавливается MinHook | Проверьте сеть и SHA256. Не обходите checksum; сообщите точную ошибку. |
| Runtime already exists without marker | Выберите новую папку для приватной копии; setup не перезаписывает неизвестную установку. |

Лог может содержать локальные пути. Перед публикацией отчёта удалите личные данные;
не прикладывайте игровые DLL, карты, сохранения, модели, звуки или приватную копию целиком.
Поддержка этого хобби-проекта предоставляется по возможности.
