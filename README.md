# Warcraft CS by Yazgul — 0.1.0

Counter-Strike 1.6 внутри Warcraft III: управляйте своим героем или юнитом от первого лица,
стреляйте и играйте на обычных картах, в кампании и совместимых кастомках.
Мир, противники, задания и здоровье остаются Warcraft.

Неофициальный одиночный фанатский проект. Не связан с Blizzard Entertainment или Valve.
**Публикация содержит исходники. Игровые файлы, модели, звуки, карты, сохранения и готовые
бинарники не распространяются. Нужны ваши собственные установленные игры.**
Проект создан Yazgul совместно с Codex (GPT-6); это ранний прототип с известными ограничениями.

## Возможности

- FPS/RTS по F6, полноэкранный запуск, относительный обзор мышью, скрытие модели своего юнита.
- WASD, прыжок, приседание, ускорение/трение и скорость оружия в стиле CS.
- AK47, M4A1 и USP без глушителей, AWP с двумя уровнями увеличения, нож, C4 и большой меч.
- Оригинальные расчёты угловой отдачи AK/M4 и USP/AWP, восстановление прицела и очередь.
- Удары ножа/меча обеими кнопками, штатный звук CS, индикатор попадания без крови.
- Урон юнитам, зданиям и воротам; союзникам 50%. C4 — 2500 базового урона по области.
- Оглушение, сеть, замедление и запрет атаки Warcraft ограничивают действия FPS.
- E подбирает предметы/руны через настоящий инвентарь; успешная руна возвращает 20% боезапаса.
- H собирает только своих юнитов для совместного боя, O — для следования, J освобождает отряд.
- Настройки боезапаса и урона через INI с перечитыванием по F8.

## Требования

Windows x64, **Warcraft III 1.26a x86** (`Game.dll` версии `1.26.0.6401`) и установленный
Counter-Strike 1.6 с папками `cstrike/models` и `cstrike/sound`.
Для сборки нужны Git, Python 3.10+ и Visual Studio 2022 / Build Tools с компонентом
**Desktop development with C++**, MSVC x86 и Windows SDK. Поддерживается OpenGL.
Настройка создаёт локальную копию Warcraft; предусмотрите место ещё для одной установки.

## Установка и запуск

В PowerShell:

```powershell
git clone https://github.com/whitestridee/warcraft-cs.git
cd warcraft-cs
git switch release/0.1.0
.\setup.cmd -WarcraftDirectory "E:\Warcraft III" -CounterStrikeDirectory "C:\SteamGames\steamapps\common\Half-Life\cstrike"
.\play.cmd
```

Замените пути на свои. Setup загружает закреплённый MinHook отдельно, устанавливает NumPy
в локальное окружение, читает ваши модели/звуки CS и собирает мод в приватной копии игры.
Оригинальные установки не изменяются. Подробности, дополнительный скин меча и удаление:
[INSTALL.md](INSTALL.md).

Выберите «Один игрок» → «Сражения» или «Кампании», затем выберите своего живого юнита
и нажмите F6. Каждая карта не требует отдельного редактирования. После смены карты включите FPS снова.

## Управление

| Клавиша | Действие |
|---|---|
| F6 / F10 | FPS ↔ RTS / меню паузы с возвратом RTS |
| WASD / мышь | Движение / обзор и прицеливание |
| Shift / Ctrl / Space | Ходьба / приседание / прыжок |
| Левая кнопка | Выстрел или обычный удар |
| Правая кнопка | Нож/меч: сильный удар; AWP: два увеличения и обычный обзор |
| R / F7 | Перезарядка / полный боезапас, включая C4 |
| 1 / 2 / 3 / 4 / 5 / 6 / 7 | AK47 / M4A1 / USP / AWP / нож / C4 / меч |
| Удерживать ЛКМ с C4 | Установка за 3 секунды, стоя на земле |
| E | Ближайший предмет или руна, если юнит имеет доступный инвентарь |
| H / O / J | Свои юниты: следовать и драться / следовать без атак / освободить отряд |
| F8 | Перечитать настройки |

## Настройки

Файл по умолчанию: `.local/warcraft-cs/WarcraftCS/WarcraftCS.ini`.
Измените его и нажмите F8 в FPS.

- `[Runes] AmmoPercent=20`, `AmmoWeapons=all` либо `current`.
- `[Damage] Mode=weapon` — фиксированный урон; `Mode=hero` — текущая средняя атака
  **любого** управляемого юнита × `HeroMultiplier` оружия, включая крипов.
- `[Damage] AWPOneShot=true` — принудительное убийство врагов AWP только в режиме `weapon`.
- `[Squad] RecruitRadius`, `MaxUnits`, `FollowDistance`, `CombatLeash` — параметры отряда.

Броня остаётся штатной; союзникам применяется коэффициент 0,5. Обычный предмет не даёт патроны.
Штатный исследованный «Рюкзак» у крипов принимает экипировку, но Warcraft запрещает ему
активировать руны/тома; отказ не выдаёт боезапас. Переполненный инвентарь также не выдаёт награду.
У юнита без обычной атаки режим `hero` даёт нулевой урон. C4 использует фиксированный `[C4] Damage`.

## Совместимость и ограничения

Только offline single player; сетевой режим не поддерживается. Мод подключается глобально,
но прохождение всей кампании и совместимость с каждой кастомкой не проверены.
Скрипты конкретной карты могут конфликтовать с камерой или управлением юнитом.
Карты без живых собственных юнитов не предоставляют FPS-персонажа.
Хитбоксы приближены габаритами моделей, а не каждой костью. Расчёты отдачи перенесены,
**полный разброс/точность пуль и весь клиент GoldSrc не перенесены**.
Нет экономики, раундов и покупки оружия CS. См. [TROUBLESHOOTING.md](TROUBLESHOOTING.md).

## Исходники и проверка

`src` — runtime и независимые расчёты, `tests` — численные проверки и опциональные
сцены для отдельной тестовой карты, `tools` — сборка/конвертация/аудит, `setup` — подготовка
ваших локальных файлов. Код отдачи, инвентаря, отряда, камеры и звука разделён по обязанностям.

```powershell
.\tools\test-all.ps1
python .\tools\audit_sources.py --revision HEAD
```

Итоги проверки 0.1.0: [docs/VALIDATION.md](docs/VALIDATION.md).
